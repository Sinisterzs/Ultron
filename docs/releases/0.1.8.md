# ULTRON 0.1.8

## Wake Word & Detecção de Despertar

- **Prevenção de Repouso Infinito (Fail-Safe)**: Corrigido o bug onde a ativação de Wake Word sem os modelos previamente baixados deixava o ULTRON preso no estado `SLEEPING` sem detector ativo para acordá-lo. Agora o sistema verifica a prontidão real dos modelos antes de dormir; se não houver detector pronto, o app inicia acordado em `LISTENING` e notifica no log que o download é necessário.
- **Botão Manual de Despertar Sempre Visível**: O botão `👂 WAKE NOW` na barra de controles agora permanece visível e operacional sempre que o assistente estiver em repouso (`SLEEP`), independentemente do status de download dos modelos.
- **Compatibilidade do Instalador com Runtime Windows Embeddable**: O processo de download e instalação de dependências do Wake Word (`openwakeword`) via `core/wake_word.py` foi atualizado para ambientes empacotados. Ele resolve o executável `python.exe` caso chamado sob `pythonw.exe`, utiliza `--isolated` e `--no-build-isolation` para evitar erros de isolamento de build no Python embeddable, e executa em segundo plano sem abrir janelas de console.

## Validação

- Verificado com testes automatizados (`test_installation_foundation.py`, `test_void_interface.py`, `test_hud_frame_cache.py`) e validação estática de AST.
- Validação manual de microfone e modelos neurais locais recomendada após o download.
