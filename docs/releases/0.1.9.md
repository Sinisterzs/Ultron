# ULTRON 0.1.9

Hey everyone! In this update, we focused heavily on giving ULTRON a proper modular plugin management experience, introducing visual intelligence capabilities, and polishing the window interactions so everything feels snappy and cohesive.

---

### What's New

#### Holographic Plugin Control Center
- **In-Place Module Configuration**: You no longer have to deal with old detached settings windows. When you click **Configure Module Settings** (like for Spotify credentials), the settings form renders right inside the selected module card view. Changes apply cleanly upon saving without disrupting your current browsing context.
- **Third-Party Plugin Settings**: Plugins can now supply their own configuration schema, and the control center automatically renders dedicated form fields, hints, password reveal toggles, and state persistence.
- **Clean VOID OS Aesthetic**: Chamfered borders, pure `#000000` background, ruby red `#ff2a4b` brackets, Consolas typography, and zero unwanted horizontal scrollbars.

#### Smart Vision Plugin
- **Visual Understanding**: Added an isolated visual intelligence module capable of analyzing screen regions and camera snapshots.
- **Strict Privacy & Consent Gates**: Before any visual data is sent to the model, an explicit HUD consent banner appears asking for permission (`Once`, `This Session`, or `Always`). Visual actions never execute file alterations or clicks behind your back.

#### Fluid Drawer Animations & Layout Docking
- **Smart Slide-Out Physics**: The plugin manager now slides in smoothly from the left SYSTEM dock using a 200 ms cubic ease-out curve, completely synchronized to the HUD animation clock (`HudCanvas.pacedFrame`).
- **Instant In-Place Switching**: If you already have a drawer open (such as Memory, Voice, or Core), switching between them and Plugins happens instantly in-place—no redundant slide animations when you're already actively navigating.
- **Anchored Positioning**: The panel now pins cleanly right beside the left animated primary dock in both windowed mode and maximized full-screen mode, never floating randomly in the center of the display.
- **Mutual Exclusion**: Opening Plugins automatically hides drawer panels, and opening Memory or Voice immediately tucks away the plugin center so widgets never render on top of each other.

#### Bug Fixes & Refinements
- Fixed an `AttributeError` on stored memory facts status when opening the Memory drawer.
- Added safe fallbacks for window titlebar buttons and dock coordinate mapping.
- Cleaned up event dispatching and unlinked internal developer agent notes from repository tracking.

---

### Installation & Updating
- Download **`ULTRON-Setup.exe`** below to install or update.
- Existing installations running 0.1.3+ will automatically detect the new version and notify you discreetly on the bottom dock.
