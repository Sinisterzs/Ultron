# ULTRON 0.1.10

Hey everyone! This is a quick but crucial update addressing the startup crash reported on packaged installations, along with a handy new self-repair capability built directly into the boot launcher.

---

### What's New

#### In-Launcher Update & Self-Repair
- **Direct Update Checks from Boot Launcher**: You'll now notice a **PROCURAR ATUALIZAÇÃO** button right in the launcher header. You can check for newer releases anytime, even before the main HUD loads.
- **Automatic Recovery on Startup Failures**: If the main application ever encounters an error or crashes on boot (for example, missing files or broken dependencies), the launcher no longer leaves you stranded with a bare error code. It automatically presents a prominent **BUSCAR ATUALIZAÇÕES PARA REPARAR** button.
- **One-Click Download & Apply**: When an update is detected, clicking the button downloads the verified release with live progress right on the launcher's HUD bar and hands off directly to the updater, restarting cleanly into the new version.
- **Offline & Dev Fallbacks**: If you're developing from source or running in an environment without installer access, it opens the GitHub Releases page in your default browser.

#### Bug Fixes & Stability
- **Fixed Launcher Exit Code 1 Crash**: In `v0.1.9`, newly introduced UI modules (`ui_plugins_center.py` and `ui_vision.py`) were inadvertently omitted from the setup payload allowlist in `installer/prepare_payload.py`. Packaged installations were missing these files, causing an immediate `ModuleNotFoundError` on boot. Both modules are now fully bundled in the setup manifest.
- **Repository Hygiene**: Untracked internal developer notes and local workspace files (`AGENTS.md`, `PROMPTS_CODEX.md`, `COMO_INSTALAR.md`) across all folders and added them to `.gitignore`.
- **Streamlined Readme Notes**: Condensed the README patch history to the 5 latest releases with full detailed notes hosted right here on GitHub Releases.

---

### Installation & Updating
- Download **`ULTRON-Setup.exe`** below to install or update.
- If your current installation encountered the exit code 1 error on 0.1.9, you can simply run the new **`ULTRON-Setup.exe`** once to apply the fix, or use the new launcher update button if you're on a compatible build.
